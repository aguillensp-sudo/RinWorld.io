## Síntoma

**La spec de INV-07 promete lo que el modelo de datos no expresa:** el ejemplo de VERA (§5) habla de «excluir toda Asia MENOS Japón», pero `inventory_exclusions` guarda exclusiones por organización, por país o por continente, **sin excepciones**: excluir un país dentro de un continente ya excluido es redundante y no se puede permitir uno. La pantalla lo deja fuera de alcance. Y el selector de continentes lista **seis** (sin Antártida, como la spec) aunque la base admite siete
